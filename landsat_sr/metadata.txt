description=Enlarge RGB and monochrome Landsat images four times for clearer display, offline.
about=SR Module for Landsat enlarges prepared 8-bit or 16-bit RGB and monochrome rasters by a factor of 4 and saves the result as a GeoTIFF. It uses a general-purpose Real-HAT model through ONNX Runtime. Inference runs on your computer. Input must be a local raster file. Output is for visual display and does not preserve Landsat scientific values. External dependency: the QGIS repository package needs a separately supplied 64-bit Windows runtime (Python 3.11 or later, NumPy, ONNX Runtime) and model. Select them with the runtime setup menu. The plugin does not download them. Author: Vipul Chhikara, New Delhi, India.
