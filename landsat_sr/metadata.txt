about=**WINDOWS ONLY**
 This plugin needs 64-bit Windows and QGIS 4.2 (tested on QGIS 4.2.0). Linux and macOS are not supported.

 SR Module for Landsat enlarges prepared 8-bit or 16-bit RGB and monochrome rasters by a factor of 4 and saves a GeoTIFF. It uses a general-purpose Real-HAT model through ONNX Runtime. Inference runs on your computer.  Input must be a local raster file. Output is for visual display only. The model estimates the added detail. The output is not measured data and not Landsat reflectance.

 IMPORTANT: SETUP IS NEEDED BEFORE FIRST USE.  The plugin package has no runtime and no model, and the plugin does not download them. Follow the below instructions:

 1. Download landsat_sr_runtime_windows_x64.zip from https://github.com/vchhikara/SR-Module-for-Landsat/releases/download/v0.7.0/landsat_sr_runtime_windows_x64.zip
 2. Check the file. Open PowerShell in the download folder and run the command at the end of this line. The Hash value must be 54b502d8ef1d38f5995f534fe86647e0a3b8ca034e2a9d0046c9929917d0f9d8 (capital and small letters are equal): Get-FileHash .\landsat_sr_runtime_windows_x64.zip
 3. Extract the ZIP to a permanent folder that only you can change.
 4. In QGIS, open Raster > SR Module for Landsat > Configure SR runtime and model.
 5. Select runtime\python.exe and weights\real_hat_64.onnx, then confirm that you trust the runtime.
 6. Open SR Module for Landsat from the Raster menu. Select an input raster and a new .tif output path, then select OK.

 **Do not add or change files in the runtime folder. A change blocks processing until you configure the runtime again.**


 The model comes from the HAT project (https://github.com/XPixelGroup/HAT) under the Apache License 2.0. The licenses of the included components are in the licenses folder of the runtime ZIP.
