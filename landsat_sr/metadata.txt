description=Enlarge RGB and monochrome Landsat images four times for clearer display, offline.
about=SR Module for Landsat enlarges prepared 8-bit or 16-bit RGB and monochrome rasters by a factor of 4 and saves the result as a GeoTIFF. It uses a general-purpose Real-HAT model through ONNX Runtime and runs offline. The output serves visual display only. It does not preserve Landsat scientific values, and the added detail is estimated, not verified ground information. The plugin needs the offline runtime and model files, which target 64-bit Windows and are not part of this source package. Author: Vipul Chhikara, New Delhi, India.
