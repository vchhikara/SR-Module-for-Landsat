description=Enlarge RGB and monochrome Landsat images four times for clearer display, offline.
about=SR Module for Landsat enlarges prepared 8-bit or 16-bit RGB and monochrome rasters by a factor of 4 and saves the result as a GeoTIFF. It uses a general-purpose Real-HAT model through ONNX Runtime and runs offline after setup. Output is for visual display and does not preserve Landsat scientific values. The QGIS repository package requires a separately supplied 64-bit Windows runtime and model; use the runtime setup menu to select them. Author: Vipul Chhikara, New Delhi, India.
